# Security policy

## Reporting a vulnerability

Report security vulnerabilities privately through GitHub: open this repository's **Security** tab
and choose **Report a vulnerability**. Do not open a public issue for a security problem.

Include what you found, the steps to reproduce it, and the versions of this app and of
`@kenshiki/identity-capture` you used. Use synthetic data only; never include real identity
documents, SSNs, phone numbers or other personal data in a report.

## Scope

This policy covers this reference app and the `@kenshiki/identity-capture` package it installs.
Report a vulnerability in another dependency to that project, and tell us if it affects this app.

## Supported versions

Security fixes land in the latest release of this app and the latest release of the SDK package.
